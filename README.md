# Investa

**Investa** is a modern web-based stock trading platform inspired by Zerodha.

It is built from scratch using **React**, **Vite**, **Node.js**, and **Express** to simulate real-time stock trading, portfolio management, and market analytics.

This project is created by **Shoaib Navi** as a learning and portfolio project. All code is original and designed to mimic the core functionality of a trading platform while being fully web-based.

---

## Features

- Real-time stock price updates (simulation)
- Buy/Sell stocks functionality
- Portfolio tracking with basic analytics
- User authentication and dashboard
- Clean, responsive, and modern UI
- React + Vite frontend for fast development
- Node.js + Express backend for API handling

## Installation

1. **Clone the repository**
```bash
git clone https://github.com/YourUsername/Investa.git
```

2. **Install frontend dependencies**

cd Investa/frontend
npm install


3. **Start frontend development server**

npm run dev

Open your browser at: http://localhost:5173

1. **Install backend dependencies**

cd ../backend
npm install


5. **Start backend server**
node index.js
